# Cleanr App — Public Preview

This repository is a sanitized public preview of Cleanr's current product direction, derived from the authoritative private Cleanr application.

## Included

- Public-facing Cleanr preview experience
- Current Cleanr brand direction and residential positioning
- Vite + React + TypeScript + Tailwind build configuration
- Vercel-compatible SPA routing

## Intentionally excluded

- Environment files and credentials
- Production Supabase implementation, migrations, and Edge Functions
- Stripe and Kinex backend implementation
- Internal operational and forensic documentation
- Private application history and production repository metadata

The production source of truth remains private. This repository is intended for safe public product demonstration only.

## Local preview

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
